# Sightline demo video script

**Length:** 1:50 target, under 2:00 hard limit. **Audio:** voiceover only, no music. **Capture:** phone-width browser (about 390 px) for the app, desktop width for two shots of the stage and rail side by side. Dark theme throughout.

**Rules for every frame:** fictional clubs and players only (Arden Athletic, Hollow Vale). No real club names, crests, league lion or wordmark, broadcaster, Microsoft or Copilot logos. The Azure portal shot shows resource names only, cropped to hide product logos. Pre-check the recording for notifications and bookmarks.

**Framing:** Sightline is a new feature inside the Premier League app's Match Centre. The look matches the app (dark aubergine, rounded purple cards, split-colour match header, pill buttons, underline tabs) so it reads as part of it, not a separate product.

**Demo match:** Arden Athletic 3-2 Hollow Vale (seed 587). Hollow Vale lead 2-0 (30', 59'), Arden level at 73' and 77', substitute Teodor Rennick wins it in the 91st minute. Arden's centre back Rhys Tremblay (number 5) makes 25 defensive actions.

## Recording checklist

- Start the capture with playback already running at about 72:00 so shot 1 is live from frame one
- Set the lens to Casual before shot 3 so the lens change in shot 4 is visible
- Have the claim text ready to paste for shot 6
- Record each shot separately and cut tightly; the voiceover runs about 230 words, which fits at a calm pace
- Export 1080p, check the total runs under 2:00
