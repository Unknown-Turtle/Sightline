# Sightline: elevator pitch

Sightline turns match data into match intelligence fans can check. It is a second-screen feature for the Premier League app's Match Centre: a 3D replay of the match with live points such as "Arden's number 5 is holding the back line together", each backed by an evidence reel of the exact moments for and against it.

Fans choose a lens. Casual explains in plain words, Tactical shows the numbers and the shape, and Commentator adds history and trivia a commentator could say on air. Ratings, a claim checker, detected set routines and translations sit alongside.

The problem it solves: football talk runs on vibes, and AI summaries make it worse when they invent numbers. In Sightline, code computes every number and the AI only phrases. Analyst, trivia, narrator and checker agents run on Microsoft Foundry; the checker verifies every figure before a line is shown, and every insight carries a receipt.

Built with Microsoft Foundry (AI Services, project and model deployment), Azure Static Web Apps, Azure Storage, Application Insights and Log Analytics, managed identity, and Bicep, with an optional live path on Azure Event Hubs and Azure Functions. All match data is synthetic and fictional.
